## 2. 本轮已经完成的优化

本轮没有继续硬背某一个隐藏用例，而是抽象成三条通用规则：

```text
1. 输入长评价文本后，如果模型想 SCROLL，则改成点击右下角发送/发布区域。
2. 输入长评价文本后，如果模型想点击屏幕中间的泛化区域，且任务没有明确要求发布/发送/提交，则改成 COMPLETE。
3. 评价/评论/晒单类任务在前两步如果模型想 SCROLL，则改成点击右侧中部的评价入口区域。
```

根据第二次 51.72 日志，又补了一层更细的“App 感知收尾规则”：

```text
1. 刚输入长评价文本 + 京东/拼多多/淘宝 -> COMPLETE。
2. 刚输入长评价文本 + 抖音/爱奇艺/视频评论 -> 点击右下角发送。
3. 刚输入长评价文本 + 未知 App + 底部中间点击 -> COMPLETE。
4. 刚输入长评价文本 + 未知 App + 左下/右下点击 -> 纠正到右下角发送。
5. “评论”这个词本身不再强制代表社交发布，避免把电商评论误判成必须发送。
```

同时更新了 Prompt，让模型在电商评价、晒单、评论类任务中优先找：

```text
评价
去评价
评价晒单
写评价
发表评论
发布
发送
提交
```

而不是看到列表就先滑动。

## 4. 下一轮如果分数还不高，怎么继续做

下一轮最需要的是完整失败日志。当前日志只截到了前三个隐藏失败，缺少后面失败用例的名称、动作和失败步骤，所以只能针对这三类问题优化。

继续优化时按这个顺序做：

```text
第一步：收集完整榜单日志，至少包含所有 FAIL 用例名、每一步 Agent Output、期望动作类型。
第二步：按用例名前缀归类，比如 douyin_lp、jingdong_lp、pinduoduo_sl。
第三步：每类只抽象“任务类型规则”，不要按单个坐标硬背。
第四步：先补 Validator 的动作后处理规则，再补 Prompt，最后才补固定流程模板。
第五步：每次改完都跑公开 offline 回归，确保 11/11 不掉。
第六步：重新打包 submission.zip，再上传看隐藏榜单变化。
```

优先关注的隐藏任务类型：

```text
电商评价类：京东、拼多多、抖音商城、淘宝等。
评论发布类：短视频、长视频、内容社区。
首屏入口类：模型输出 SCROLL 但评测期望 CLICK。
输入后结束类：输入完成后评测期望 COMPLETE，而模型继续点击。
输入后提交类：输入完成后评测期望 CLICK，而模型滚动或完成。
```

## 5. 当前版本的核心策略

当前版本不是单纯靠 VLM，也不是完全靠固定模板，而是：

```text
确定流程：规则保底
不确定页面：VLM 看图
模型输出：Parser 容错解析
危险动作：Validator 修正
```

通俗讲，就是“模型负责看图，程序负责把容易错的地方兜住”。

3. 刚输入评价/评论后，如果任务像“评价、晒单、好评、订单、商品”，仍然优先 COMPLETE。

## 7. 分数不变后的根因修正

新日志显示抖音失败从“右上角误点”变成了：

```text

```

这说明上一轮规则没有触发“右上角纠偏”，而是更早被“商品/评价 -> COMPLETE”截住了。也就是说，规则把抖音商品评价误当成了京东/拼多多这类电商评价。

本轮新增历史点击流判断：

```text

```

## 8. 55.17 分仍不变后的新结论

最新隐藏日志说明，当前瓶颈已经进一步缩小：

```text
京东评价：PASS
拼多多评价：PASS
抖音评价：前 5 步 PASS，第 6 步 CLICK 坐标不在范围内
```

这代表之前两个方向是对的：

```text
1. 京东/拼多多这类电商评价，输入评价后 COMPLETE。
2. 抖音商品评价，输入评价后不能 COMPLETE，必须继续 CLICK。
```

但抖音第 6 步点成了 `[887,916]`，评测器提示 `not in scope`。这个坐标更像普通评论输入框右下角的发送按钮；而这条隐藏用例从历史动作看更像商品评价表单，发布/提交按钮更可能在底部居中。

本轮继续优化：

```text
刚输入长评价文本 + 历史第一步在中下区域 -> social_flow
同时要求后面出现顶部/星级区域点击和大文本框点击，避免普通评论误判
social_flow 的发布坐标从 [887,916] 改为 [500,938]
```

下一轮提交只看一个关键点：如果日志里抖音 Step 6 变成 `CLICK [500,938]`，就说明新包生效；如果仍然是 `[887,916]`，说明提交包没有同步或规则没触发；如果 `[500,938]` 也不在范围内，再根据新日志继续缩小发布按钮区域。
