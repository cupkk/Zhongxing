# 资料索引

这份索引用来记录本轮优化参考过的资料，方便后续答辩或继续优化时回查。

## 千问/Qwen 系列

- Qwen2.5-VL 官方博客  
  https://qwenlm.github.io/blog/qwen2.5-vl/  
  重点：官方说明模型具备视觉 Agent、电脑/手机使用、点/框定位和稳定结构化输出能力。

- Qwen2.5-VL Technical Report  
  https://arxiv.org/abs/2502.13923  
  重点：视觉定位、文档/图表理解、移动设备交互能力，是选择千问 VLM 做 GUI Agent 的依据。

- Qwen3-VL Technical Report  
  https://arxiv.org/abs/2511.21631  
  重点：长上下文、多图/视频推理和 agentic decision-making。如果官方统一 API 支持，后续可尝试作为更强后端。

## 手机 GUI Agent

- Mobile-Agent: Autonomous Multi-Modal Mobile Device Agent with Visual Perception  
  https://arxiv.org/abs/2401.16158  
  重点：先视觉感知，再任务分解，再逐步操作；不依赖 Android XML 元数据。

- AppAgent: Multimodal Agents as Smartphone Users  
  https://arxiv.org/abs/2312.13771  
  重点：简化动作空间，通过自主探索或人类演示形成知识库。

## GUI grounding 与动作模型

- SeeClick: Harnessing GUI Grounding for Advanced Visual GUI Agents  
  https://arxiv.org/abs/2401.10935  
  重点：只依赖截图也可以做 GUI Agent，但核心瓶颈是 GUI grounding。

- OS-ATLAS: A Foundation Action Model for Generalist GUI Agents  
  https://arxiv.org/abs/2410.23218  
  重点：跨平台 GUI grounding 数据和动作模型能增强泛化。

- UI-TARS: Pioneering Automated GUI Interaction with Native Agents  
  https://arxiv.org/abs/2501.12326  
  重点：统一动作建模、系统 2 推理、反思轨迹训练，是目前 GUI Agent 的重要方向。

## Benchmark 与评测启发

- AndroidWorld: A Dynamic Benchmarking Environment for Autonomous Agents  
  https://arxiv.org/abs/2405.14573  
  重点：真实评测会动态生成任务、改变自然语言表达，并用程序检查系统状态。对应本比赛，隐藏集低分不奇怪，必须根据失败类型做泛化规则。
